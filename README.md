# MDG-Mamba
MDG‑Mamba: gradient‑enhanced macro‑micro decoupled framework for photovoltaic power forecasting. It captures PV variations via gradient‑based enhancement, separates long‑term trends and high‑frequency fluctuations, and uses multi‑frequency refinement for long‑range modeling. Experiments show average MAE reduction of ~8.5% on real‑world PV datasets.
